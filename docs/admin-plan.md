# 本地书架后台实施计划

用户已确认：在 /admin/ 本地管理书籍，直接上传封面，草稿保存在本机，导出ZIP后覆盖项目文件并自行推送GitHub。

## 范围与数据边界

- 独立Astro项目；只在开发模式、回环地址下开放后台，不修改原博客。
- 书籍增删改：书名、分类、阅读状态、0—10评分、日期、封面URL或上传图片。
- IndexedDB单事务保存书籍和图片Blob；失败保留编辑内容，不提示保存成功。
- 允许JPEG、PNG、WebP、GIF、AVIF，校验实际图片格式、限制单张10MB；不接受SVG。
- ZIP包含src/data/books.ts及public/covers/图片；只收录仍被引用的上传图片，不下载第三方封面。
- fflate仅用于ZIP生成；用户手动解压覆盖、验证、提交，不自动推送或删除已有封面。

## 执行与验证

1. 先编写数据校验、路径安全、导出和图片格式测试，确认缺少实现时失败。

## 验收结果

- 模型测试：资料范围、URL与路径安全、图片字节识别、ZIP内容、闲置封面清理。
- 浏览器隔离上下文实测：11本初始书籍→新增并上传PNG→刷新恢复图片→编辑→ZIP导出→删除→刷新恢复删除→390px编辑弹窗。
- 非法图片被拒绝；模拟存储空间不足后编辑内容不丢失，重试保存成功。
- 浏览器实际ZIP验证：包含12本书籍数据和新封面，不含后台内部ID。
- 正式构建admin只包含本地提示，不含管理表单或管理脚本。
