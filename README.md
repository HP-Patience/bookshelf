# 独立书架

![书架页面预览](public/readme-cover.png)

一个可以独立运行的书籍展示与阅读状态筛选站点。项目从「团子和蛋糕的博客」书架页面提取，书本卡片、3D 纸页、分类与状态筛选样式直接复用博客源码；不依赖博客主站即可开发和构建。

## 功能

- 按书籍分类筛选，并显示每类藏书数量。
- 按阅读状态筛选：读过、在读、想读、搁置、抛弃。
- 显示阅读状态统计、封面和评分。
- 本地后台直接管理项目文件、上传封面转WebP，并可执行Git提交与推送。
- 复用原书架的 3D 书本卡片、悬停翻转、书脊与纸页效果。
- 桌面端每行 5 本、每页 10 本；移动端每行 3 本、每页 6 本。
- 适配窄屏，并支持键盘焦点和减少动态效果偏好。

## 本地运行

需要 Node.js 与 pnpm。项目使用 pnpm 9.14.4。

在项目目录执行：

```sh
pnpm install
pnpm dev
```

开发服务器默认地址为 http://localhost:4321/。

## 检查与构建

```sh
pnpm test
pnpm check
pnpm build
pnpm preview
```

- `pnpm test` 检查书卡保留整本书的 3D 旋转，并验证卡片与书架网格 CSS 和原博客源码一致。
- `pnpm check` 运行 Astro 类型与模板检查。
- `pnpm build` 生成静态站点到 `dist/`。
- `pnpm preview` 本地预览构建结果。

## 书籍数据

书籍清单位于 `src/data/books.ts`，每本书包含书名、分类、阅读状态、评分、封面地址、开始日期和结束日期。旧 `published` 日期为兼容保留，不自动当作阅读日期。直接编辑该文件即可维护独立书架。

状态值：

| 值 | 状态 |
| --- | --- |
| 1 | 想读 |
| 2 | 读过 |
| 3 | 在读 |
| 4 | 搁置 |
| 5 | 抛弃 |

书籍封面已下载到本地，展示路径为 `/covers/文件名.webp`（相对于本站根目录）。原始图片保存在 `public/covers/originals/`。当前项目不包含博客文章正文、评论或详情页。

## 目录结构

```
src/
├── components/    # 原博客书架组件与书本卡片
├── data/          # 独立书籍数据
├── layouts/       # 独立页面框架
├── pages/         # Astro 路由
└── styles/        # 原书架样式及独立页面基础样式
tests/             # 书本动效与源码样式一致性测试
public/            # 图标等静态资源
```

## 技术栈

Astro 7、TypeScript、原生 CSS 与浏览器原生交互；本地开发服务写入文件，sharp转换封面WebP，不使用额外 UI 框架。

## 本地后台管理

1. 使用 Node.js 24，执行 `pnpm dev`，打开 `http://127.0.0.1:4321/admin/`。
2. 新增、编辑或删除书籍会直接保存到 `src/data/books.ts`，刷新书架即可看到更新，不再需要导出ZIP。
3. 开始日期、结束日期可留空；结束日期不能早于开始日期。既有书籍的旧日期原样保留，不推断阅读时间。
4. 上传封面或下载HTTP(S)封面链接后，原图保留在 `public/covers/originals/`，自动生成 `public/covers/*.webp`。书籍展示使用本地WebP路径。单张最多10MB，支持JPEG、PNG、WebP、GIF、AVIF，不支持SVG。

### Git提交与推送

点击“执行推送”打开弹窗，输入提交说明，按需依次点击：

- `git add .`：暂存**整个项目所有未忽略的改动**，不只书单。
- `git commit`：使用输入的提交说明创建本地提交。
- `git push origin main`：推送main分支到origin；须事先配置好Git身份与GitHub凭据。

弹窗下方显示每个命令的实时输出与退出码。按钮不会自动串联，也不执行force push；命令失败时根据终端提示处理。需要交互登录的操作请在系统终端先完成。

### 安全与备份

- 文件写入与Git接口**仅在开发服务中开放**，检查本机连接、回环Host、同源Origin及临时操作凭证。正式构建的 `/admin/` 只显示“仅限本地使用”。
- 修改前的书单自动备份到 `.local-admin/backups/`（已被Git忽略）。保存使用修订检查：文件被其他操作修改时，要求重新读取，避免无声覆盖。
- 删除书籍不删除封面原图和WebP，替换封面也保留历史图片。
- 旧浏览器草稿未自动删除，也不会覆盖本地文件；此前尚未发布的草稿请从旧导出备份中迁移。
- 上传成功就会产生图片文件；取消书籍编辑不会删除该图片。请在提交前检查 `git status`。
